# H5 测试部署安全检查（2026-09-14）

补充：登录页取消开发模式默认账号密码；H5 附件预览禁止 HTTP 重定向，跳转链接会预览失败，请后端返回直接文件地址。原生下载无通用禁重定向选项，需服务端防止受保护文件跳转至外域，本轮未完成真机验证。

## 打包与部署边界

- 命令：`pnpm build:h5:test`；文件监听数量受限时可临时使用 `CHOKIDAR_USEPOLLING=1 pnpm build:h5:test`。
- 输出：`dist/build/h5-test/`。这是静态站点内容，不是项目源码；不要部署 node_modules、env、.git、.cert 或开发服务器。
- 页面地址：`https://oa-test.shouhuikeji.com/h5/`；API：`https://oa-test.shouhuikeji.com/shouhuiApi`。不要把页面放到 `/shouhuiApi/h5`。
- 独立脚本固定 production 编译、`/h5/` 基础路径、HTTPS API，关闭 Mock、代理、源码映射和控制台日志；运行时配置只输出明确的公开字段，不输出完整环境变量。
- 本次只生成本地测试产物，不上传、不改 Nginx、不改后端角色配置、不推送 Git。

## 已实施的前端防护

- 通用请求及上传拦截器只向配置的 API 地址范围发送会话认证头；外部地址移除 Authorization、X-Access-Token、租户及签名头，H5 禁用跨域凭据。拒绝将路径穿越、协议相对 URL、伪装域名认作可信地址。
- 入库按钮及提交函数检查 `mtl:goods:io`、方向 IN、审批通过 `status=1`、执行状态 PENDING/PARTIAL_EXECUTED；确认后重新查询申请头并匹配申请 ID。
- 权限加载失败清空旧菜单、按钮码和 fullAccess，业务路由关闭，保留首页与退出入口；缓存每 60 秒在路由进入时重新核验。
- qs 更新至 6.16.0，直接 vue-i18n 更新至 9.14.5；补齐 jszip，H5 使用 qs 官方浏览器包避免旧 CommonJS 转换残留裸模块引用。原生资源复制插件改用 Node 内置 fs，避免未声明的 fs-extra 阻断 H5 配置加载。
