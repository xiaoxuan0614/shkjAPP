# 维修保障类型回显

GET /repair/order/detail 的 result.order 和 result.products[] 返回 coverageType、coverageTypeName。优先显示接口名称，缺名称按 FULL全包、PARTIAL半包、WARRANTY质保、MIXED混合、NONE无有效保障、UNKNOWN未知回显；缺失或未识别显示未知。

报修详情新增整单保障与逐产品保障，维修日志填写中的维保类型改为本次维修保障。停止使用 warrantyTypeSnapshot/warrantyType，不按当前合同或收费方式推断，不将无有效保障等同无需报价。保障是报修时快照，续签、终止不改变历史。仅详情返回新增字段，列表不补查详情。

已通过字段和适配器测试、Vue SFC编译。PC菜单及移动端入口均未变更，无需新增权限；浏览器联调受连接超时影响，未完成真实接口页面验收。
