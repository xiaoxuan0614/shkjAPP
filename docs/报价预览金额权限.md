# 报价预览金额权限

2026-10-26，移动端与PC报价预览口径同步。

- 继续由 `/project/materialCandidate/permissions` 携带 `periodId`、`candidateId` 返回本单权限，已刷新Apifox核对；部门、创建人身份由后端判定，不用前端角色名称扩大权限。
- `canManage` 或 `canViewCost` 开放成本；`canManage` 或 `canViewQuote` 开放报价。技术部创建人、技术主管按原成本授权看到成本小计和成本合计，不因此开放对外报价。
- 仅成本可见自动成本；仅报价可见自动报价；两项均可见提供“报价金额 / 成本金额”切换，重新打开默认报价。权限变化实时收窄可见金额，两项均无权限时隐藏金额列及合计。
- 成本取物料basePrice、服务费costPrice（详情统一映射为basePrice），乘本单quantity，逐行四舍五入到分后汇总；不使用报价快照documentAmount计算成本。报价沿用原finalPrice/guidePrice与快照规则。不混算两种口径，缺失/脱敏不当零，任一行金额缺失则合计为—。
- 合同审批复用的materialOnly预览始终不展示金额或切换，不影响合同快照、正式导出、审批权限、版本及任何保存载荷。
- 回归包含成本单价/服务费小计、切换、撤销权限、缺失/零值和合同强制隐藏；原报价审批、编辑测试及SFC编译通过，未真实角色/真机联调。
