## 文档维护规则

1. 新增或修改页面时，同步更新“项目结构与功能逻辑”。
2. 页面入口、角色可见范围、PC 菜单映射变化时，同步更新“菜单角色权限与 PC 端对应”。
3. 接口 URL、请求体、关键字段或联调状态变化时，在“更新记录”注明依据和验证方式。
4. “构建通过”“Mock 验证”“真实后端联调通过”必须分开表述。
5. 墨刀原型决定主要页面结构；接口和权限以当前 Apifox、SHKJ-OA 代码及真实响应为准，历史规划不得覆盖当前事实。
