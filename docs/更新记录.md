# SHKJ 移动端更新记录

## 2026-09-08

### 库管支持批量与部分出库

- 库管申请列表不再提供绕过明细核对的整单直接出库；待处理记录统一进入申请详情后办理。
- 出库明细按物料展示“审批数量、实时库存、已出库数量、待出库数量”。“审批数量”优先读取 `approvedQty`，仅历史记录未返回该字段时回退申请数量；“待出库数量”按审批数量减去 `executedQty` 计算。
- 当前可执行且有库存的物料默认全选，支持逐项取消、全选、填写部分出库数量或点击“全部”；本次数量上限同时受待出库数量和 `currentUnitStockQty` 实时库存约束，库存未知或为零时禁止提交。
- 批量确认后只调用一次 `POST /stock/apply/execute`，同时提交 `applyId`、选中明细的 `itemIds` 及 `items[{ itemId, executeQty }]`；成功后留在详情页并重新读取明细，以便继续办理剩余数量。

### 领料申请改用项目物料当前可申请量

- “项目用料”点击“添加可申请物料”后，候选列表改为按页调用 `GET /project/materialAccount/page`，必传当前 `periodId`，搜索使用 `keyword`；不再使用 `/project/materialPlan/list` 作为领料候选来源。
- 候选项只保留 `availableApplyQty > 0` 的物料，显示“当前可申请数量”并以此作为输入、加减和提交校验上限；该数量已由后端扣除实际出库、已审批未出库和待审批申请占用。
- 物料编码直接读取总账行 `materialCode`，在候选项和已选明细的名称同一行右侧以小字显示；领料明细每条增加可直接删除的操作，删除后可从候选列表重新添加。
- 项目用料提交 `/stock/apply/add` 时补传当前分期 `periodId`。PC 与移动端提交体同步不传 `deptId/deptName/projectName/projectNo/applyUserName`，`itemList` 每项只传 `materialId/unitQty/unitName`；页面仍保留分期及物料详情用于展示。

### 合同审批详情与回款计划展示调整

- 合同审批的“回款计划”改为可横向滚动的紧凑表格，统一展示回款项、比例、计划金额和回款周期；回款周期读取 `rollbackTime` 并以“天”显示，历史空值按合同端既有规则显示 7 天，不再把 `plannedDate` 当作审批页的主要周期信息。
- 合同详情移除始终无有效回显的“项目经理”展示行；审批通过时选择并确认项目经理的流程、保存字段和接口顺序保持不变。

## 2026-09-07

### 领料申请参与项目增加生命周期过滤

- “项目用料”的项目候选调用 `GET /project/member/participatedProjects` 时增加 `periodStatus`，传入 `IMPLEMENTING,DEBUGGING,DEBUG_COMPLETED,IMPLEMENT_COMPLETED,INTERNAL_ACCEPTING,ACCEPTING`，只展示计划审批完成后至验收完成、尚未进入质保的分期；`DEBUG_COMPLETED` 仅用于兼容历史数据。
- 维修用料、劳保用品领取不调用参与项目接口；项目实施页面仍按自身业务范围查询，不复用本次领料过滤条件。

### 合同审批通过流程修正

- 合同审批弹窗不再点击“通过”后立即提交；点击后进入通过确认状态，必须选择项目经理后才能确认审批。
- 项目经理列表仅在点击“通过”后按页加载，支持按姓名搜索和滚动加载；即使合同已有经理，也必须在选择弹窗中明确确认后才能提交。
- 确认通过时，先调用 `POST /project/contract/editWithPaymentRecords` 保存选中的 `projectManagerUserId/projectManagerUserName` 和合同原有回款计划，再调用 `POST /project/contract/status` 提交 `periodId/status=1`，成功后调用 `POST /project/period/status` 提交 `periodId/status=PREPARING`。
- 点击“驳回”进入驳回确认状态，必须填写原因；确认后仅调用 `POST /project/contract/status` 提交 `periodId/status=0/approvalReason`，不保存项目经理，也不更新分期状态。

### 合同销售负责人回显与附件预览

- 实际合同详情返回的 `salesUserId/salesUserName` 均为空时，明确显示“未设置”；有姓名快照优先显示姓名，兼容 `salesUserId_dictText`，不把创建人或当前登录人冒充销售负责人。此类数据需后端补齐合同负责人字段。
- 合同文件和货物清单分别增加明确的“预览”按钮；H5 在页内打开 PDF、XLSX 和图片，PDF 支持翻页/放大，Excel 支持工作表切换、横向滚动和合并单元格；关闭预览后保留合同审批内容。
- PDF 中文映射、标准字体与解码资源随 H5 构建提供；解析库按需加载，附件只在本地浏览器解析，不发送到第三方预览服务。小程序下载后使用原生文件预览。
- 预览增加加载/失败重试、30 秒读取超时和 20 MB 文件上限；Excel 单表预览最多 500 行、50 列并显示截断提示。关闭预览取消下载与 PDF 渲染、回收资源；外部附件地址不携带系统登录凭据。
- 定向 ESLint、H5/微信小程序构建通过；独立浏览器使用模拟接口验证登录只提交账号密码、320/390 像素宽的固定审批按钮、PDF 翻页、Excel 工作表切换、驳回必填/失败保留输入、审批成功刷新及已审批禁用操作。未执行真实合同审批；真实附件及微信真机仍需联调验收。

### 账号登录暂时移除图形验证码

- 账号密码登录不再加载图形验证码、显示图形验证码输入框或校验其必填，`POST /sys/login` 只提交 `username/password`，密码加密保持不变。
- 短信登录验证码保留；账号登录成功后仍依次加载 `/sys/permission/getUserPermissionByToken` 与 `/sys/permission/getPermCode`，不改动权限初始化链路。

### 首页合同待审批弹窗

- 点击 `todoType` 或 `actionKey` 为 `PROJECT_CONTRACT_APPROVAL` 的待办，按分期 ID 调用 `GET /project/contract/queryById`，打开合同审批弹窗。
- 支持查看合同基本信息、附件及回款计划；采用固定操作区与内部滚动内容区，小屏下仍可操作通过和驳回。
- 该初版弹窗曾直接调用 `POST /project/contract/status`：通过提交 `periodId/status=1`，驳回提交 `periodId/status=0/approvalReason`。其中通过流程已按上方“合同审批通过流程修正”废止，不应再直接提交。
- 合同非待审批状态时只展示详情，不显示审批按钮。

## 2026-09-04

### 首页待办列表与成员邀请按需查询

- 首页待办列表只调用 `GET /sys/todo/page`，标题和下方摘要分别直接显示接口的 `title`、`summary`，不再按每条记录的 `bizSubId` 补查项目分期详情。
- 点击 `actionKey=PROJECT_MEMBER_INVITATION` 的待办时，使用 `bizSubId` 作为项目分期 ID 调用 `GET /project/member/myInvitations`，在当前登录人的待确认邀请中按 `periodId` 匹配；同一分期存在多条记录时优先使用 `bizId` 精确匹配成员记录 `id`。
- 邀请弹窗使用匹配记录的 `id` 调用 `POST /project/member/respond` 同意或拒绝；内容按“项目经理名称邀请您参加 / 待办 `summary` / 您的角色是 `memberRole_dictText`”展示，其中项目经理名称按 `bizSubId` 调用 `GET /project/contract/queryById` 读取 `contract.projectManagerUserName`。未找到匹配邀请时提示该事项可能已处理并刷新待办列表，不再从待办 `actionParams` 推测邀请记录和项目信息。

### 项目实施现场记录与异常打卡约束

- 签到、签退定位正常时不再显示或提交对应现场照片和异常原因；超出实施地点 200 米或签退定位异常时，必须同时填写原因并上传至少一张现场照片，分别提交 `signInRemark/signInPhotos`、`signOutRemark/signOutPhotos`。
- 实施位置不再由签到定位地点自动填充，改为操作人填写，并通过草稿及签退请求统一提交 `implementLocationName`；恢复草稿时也只回显后端已保存的实施位置。
- 项目信息删除客户联系人，保持纯展示；当前工序的现场负责人由 `/project/process/detail` 返回的 `siteLeaderId` 判断，只有现场负责人可选择其他参与人员和维护外协信息，参与人员按用户 ID 逗号拼接提交 `internalParticipantIds`。
- 实施用料选择弹层增加“全选/取消全选”，作用于当前搜索结果中同时具有计划数量和已出库数量的物料，并保留其他筛选结果的既有选择。
- 地图组件不再使用样式隐藏高德版权署名和审图标识，遵循地图开放平台的展示要求。
- “保存草稿”、实施记录进入下一页及“提交实施日志”继续统一调用 `POST /project/implementLog/signOutDraft`；请求不再提交 `hours`，由后端自行计算。`materials`、`outsources`、`internalParticipantIds`、`vehicleNo`、`mileage` 仅在有填写值时加入请求体。
- 签退页“查看实施日志填写内容”调整为“查看实施日志”，点击后不再弹出内容摘要，直接返回实施日志的实施记录页继续查看或修改。

## 2026-09-03

### 领料申请计划物料选择优化

- 移动端原“用料申请”统一更名为“领料申请”，同步页面标题、首页入口、角色预览、库管出库记录及申请详情文案；接口枚举和路径保持不变。
- 项目用料选择项目后不再立即加载计划物料；只有点击“添加计划内物料”时才调用 `/project/materialPlan/list`，按 `pageNo/pageSize` 每页加载 20 条并在滚动到底时继续加载。
- 计划物料弹层支持跨页多选、取消不落入申请明细、确认后统一回填；候选项只使用当前分期计划接口返回且计划数量大于 0 的物料，未纳入计划的库存物料不显示。
- 物料弹层增加“全选/取消全选”，作用于当前已懒加载并符合搜索条件的物料；不会为了全选一次性请求尚未加载的全部计划数据，其他页已选项保持不变。

### 首页待办同步最新接口契约

- 首页待办只调用 `GET /sys/todo/page`，请求统一收口到 `src/service/todo.ts`；分页参数为 `pageNo/pageSize`，单页上限按文档使用 100，顶部待办数量直接读取分页返回的 `total`。
- 待办内容读取 `title/summary/dueTime`，`actionParams` 按 JSON 字符串解析；项目待办优先使用 `bizSubId` 作为分期 ID，并将旧 `PLAN_APPROVAL` 枚举修正为 `PROJECT_PLAN_APPROVAL`。
- 待办接口失败时列表置空、数量归零，不再额外调用 `/sys/todo/summary`。
- 首页进入登录跳转期间不再提前请求权限、项目和待办接口；只有当前账号存在 token 时才加载工作台数据。
- 项目邀请弹窗增加可视区域最大宽高、内部滚动、长项目名称与角色自动换行、小屏紧凑布局和底部安全区适配，避免窄屏或大字号下内容及操作按钮超出屏幕。
- 项目邀请弹窗进一步拆分为“固定标题和操作区 + 中间信息滚动区”，同意、拒绝按钮始终保留在可视区域；删除重复的“邀请您参与项目”标题文案。
- 旧入口 `/pages/ops/home` 统一重定向到公共首页 `/pages/home/index`，角色预览入口同步更新，避免仍进入旧页面看到旧 `todo__desc` 结构。
- 首页待办后续的列表展示和项目成员邀请点击逻辑，已按 2026-09-04 的最新接口文档调整，以上方“首页待办列表与成员邀请按需查询”为准。

### 实施打卡同步最新实施记录接口

- 实施工序来源由已废弃的 `/project/process/list` 调整为 `GET /project/process/detail`，继续读取 `result.records` 并按最早计划开始时间默认选中。
- 选择工序后先查询 `GET /project/process/status` 校验工序归属，再查询 `GET /project/implementLog/unsignedStatus` 判断当前人员是否存在未签退记录；不再把工序 `IN_PROGRESS` 直接当作未完成打卡。
- 签到仍调用 `POST /project/implementLog/signIn`，签到和签退的 200 米范围由后端按当前分期全部实施地点复核；位置异常时分别提交 `signInRemark`、`signOutRemark`。
- 施工内容、车辆、里程、施工日志照片、参与人员、实际用料和外协统一通过 `POST /project/implementLog/signOutDraft` 暂存；实施工时由后端自行计算，移动端不提交 `hours`。正常签退和补签退前会再次保存完整草稿。
- `POST /project/implementLog/signOut` 与 `/backfillSignOut` 只提交签退坐标、`implementLocationName`、签退备注和 `signOutPhotos`，补签退额外提交 `signOutTime`；签到照片、施工日志照片和签退照片分别使用 `signInPhotos`、`photos`、`signOutPhotos`。
- 一次签退成功只结束当前实施记录，移动端不再自行把整个工序状态改成 `COMPLETED`。

### 项目详情区分参与人员与外协

- 项目详情新增独立“项目成员”区域，参与人员读取 `/project/member/list` 中已接受的非外协成员；外协读取 `/project/memberOutsource/list`，按单位分别展示计划人数和工时，不再混在“实施计划”的人员配置文本中。
- 两组数据分别显示数量、空状态和加载失败重试提示；实施计划、项目成员及外协接口参数保持不变。

### 局域网 H5 定位改用 HTTPS

- 增加 `pnpm setup:lan-https`，自动为当前局域网 IPv4 生成开发证书；证书存在时，Vite H5 开发服务自动启用 HTTPS。
- 局域网 HTTP 访问项目实施页时直接提示改用 HTTPS，不再等待定位超时；签到、签退的 200 米范围规则不变。
- 增加其他电脑导入开发根证书的操作说明；只允许分发 `.cert/rootCA.pem`，服务器私钥和根证书私钥均不得外发。
- 地图展示与人员定位解耦：项目实施地点加载成功后立即显示地点标记及 200 米范围，不再因当前设备定位失败而隐藏地图。
- 人员定位原 5 秒硬超时改为 5 秒慢响应提示、20 秒最终超时；对权限拒绝、设备定位不可用和超时分别给出可执行的处理提示，并保留迟于 5 秒返回的有效结果。

## 2026-09-01

### 登录后权限接口修正

- 账号认证仍使用与 SHKJ-OA 一致的 `POST /sys/login`；认证成功后的菜单初始化接口修正为当前系统实际使用的 `GET /sys/permission/getUserPermissionByToken`，避免菜单请求失败后清空 token、被误表现为登录失败。
- 权限缓存版本升级为 `menu-v6`，确保已缓存账号在下次登录时重新拉取正确菜单。

### 工作台移除未配置的 Mock 入口

- 当前用户菜单读取当前登录账号接口 `/sys/permission/getUserPermissionByToken`，删除从 PC 路由名称推测移动端路径的兜底；权限缓存版本升级，登录或进入首页后会重新同步。
- 首页日常办公、车辆管理和顶部业务概览只渲染后台返回且具有有效 `miniAppPath` 的入口；未在移动端角色权限中配置的巡检统计、报修维修等 Mock 模块不再显示锁定卡片。
- 删除“拥有运维工作台即放开全部 `/pages/ops/*`”和管理员前端全量放行逻辑。详情页仅按明确父页面映射继承访问权，最终接口仍由后端鉴权。
- 车辆区域由四个前端写死的日志/出行/加油/保养入口收口为一个“车辆管理”入口，是否显示以 `/pages/ops/vehicle` 是否获授权为准。

### 实施流程增加工序状态校验、服务端草稿与补签退

- 选择项目分期和工序后先调用 `GET /project/process/status`；状态为 `IN_PROGRESS` 时禁止重复签到，并提示先继续上一次实施流程。不同项目及同一项目不同工序可并行，相同 `periodId + processId` 必须完成上一轮后才能再次签到。
- 上一次流程通过 `GET /project/implementLog/signOutDraft` 恢复；实施日志第二步的保存草稿、下一步和提交日志均通过 `POST /project/implementLog/signOutDraft` 写入后端，不再依赖单一的本地实施会话。
- 正常签退调用 `/project/implementLog/signOut`，不提交签退时间；补签退调用 `/project/implementLog/backfillSignOut`，必须选择签到时间至当前时间之间的实际签退时间，并填写 `signOutRemark`。
- `/project/implementLog/edit` 已废弃并从移动端调用中移除。草稿、正常签退和补签退统一使用 `implementLocationName` 提交实施位置；实际用料按 `materialPlanId`、外协按 `outsourceMemberId` 提交。

### 实施工序字典回显与选择提示

- 项目实施签到页加载 `work_type` 字典，将工序接口 `processName` 保存的字典值转换为中文名称；字典请求失败或未匹配时保留接口原值，避免显示为空。
- 项目和实施工序选择项增加下拉箭头，工序仍默认选择 `plannedStartTime` 最早的一项，切换后同步更新工序计划时间。

### 项目搜索与候选展示统一

- 项目实施和项目用料的项目筛选统一只匹配主项目名称、分期项目名称，不再按项目编号或 ID 匹配。
