# 维修详情多余操作清理

按当前业务要求，移动端移除以下操作，不再作为维修流程的一部分：确认用料、物料损耗核销、终止未出库余量、修改联系资料。

- 删除更多菜单中的“物料结清”“联系资料”操作分组。
- 删除四项操作的表单、候选数据整理、校验、提交分支及专用样式，不只是隐藏按钮。
- 删除前端接口封装：`/repair/material/confirmUse`、`/repair/material/writeoff`、`/repair/material/closeRemainder`、`/repair/order/contact`。不改后端接口或历史数据。
- 保留点击客户查看联系方式；保留领料申请、申请还料、维修日志用料填写及已有确认记录的防误改校验。
- 历史对接文档中的上述四项不再代表当前移动端功能。历史审批记录展示不因入口移除而删除。

验证：附加操作、维修 API、维修页面、用料资源、协助流程自动测试通过。新增回归断言：四项旧操作不能打开、没有 API 封装。未进行真实业务提交，未修改 PC，未发布部署。
