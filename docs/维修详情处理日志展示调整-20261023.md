# 维修详情处理日志展示调整

- 移除详情主页面独立的“物料申请记录”“申请与审批记录”卡片，工单动态统一从“处理日志”查看。
- 处理日志继续调用现有 `GET /repair/order/logs`，保持每页 20 条、按需展开和加载更多；加载失败可重试，时间转换为空格格式。
- 不把申请当前状态拼成虚构的历史动态。协助邀请、审批、指定/退出、物料申请和审批、出入库等事件是否齐全，仍取决于后端日志接口；本次未验证服务器事件覆盖完整性。
- 保留当前协助人员摘要，以及协助详情中的撤回、修改重提、指定人员等办理能力。移除的是重复的主页面历史卡片，不是审批权限和业务功能。
- 页面逻辑、处理日志读取/错误回归、协助回归通过；未向后台写入业务数据。
